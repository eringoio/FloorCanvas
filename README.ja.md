# FloorCanvas

[English](README.md) | **日本語**

FloorCanvas は、React と SVG で構築された軽量なビジュアル間取り作成アプリです。

部屋、壁、ドア、窓、家具、テキスト、寸法線などを自由に配置・編集し、間取り図や室内レイアウトを作成できます。作成した図面は PNG、SVG、PDF として書き出すこともできます。

FloorCanvas は、ブラウザでもWindowsデスクトップアプリとしても利用できます。プロジェクトの編集や保存に、アカウントやクラウドサービスは必要ありません。

## ダウンロード

ビルド済みファイルは [GitHub Releases](https://github.com/eringoio/FloorCanvas/releases) からダウンロードできます。

### Windows版

`FloorCanvas-<version>-win-x64-portable.exe`

インストール不要のポータブル版です。ダウンロードしてそのまま起動できます。

初回起動時に、FloorCanvasのプロジェクトを保存する **ワークスペースフォルダ** を選択します。

### Web版

`FloorCanvas-<version>-web.zip`

ブラウザで利用できる静的Web版です。

ブラウザの仕様上、展開したファイルを `file://` から直接開くのではなく、ローカルWebサーバーから表示してください。

例：

```bash
npx serve .
```

または：

```bash
python -m http.server
```

表示されたローカルURLをブラウザで開けば利用できます。

ソースコードから直接起動する方法については、後述の「開発・ローカル実行」を参照してください。

## 主な機能

- **部屋・壁**
  - 部屋の作成・編集
  - 外壁・内壁
  - 直線壁、矩形壁、ポリライン
  - 壁厚やスタイルの調整

- **ドア・窓**
  - ドアの開き方向
  - ヒンジ位置
  - 開閉角度
  - 壁への配置

- **家具・図面記号**
  - 椅子
  - テーブル
  - デスク
  - 収納
  - 衛生設備
  - その他の平面図用シンボル

- **テキスト・寸法**
  - テキストラベル
  - 寸法線
  - 自動・手動の寸法表示
  - 日本語テキスト対応

- **図形**
  - 直線
  - 長方形
  - 円
  - 楕円
  - ポリライン
  - ポリゴン

- **編集機能**
  - 選択・移動
  - サイズ変更・自由変形
  - 回転
  - コピー / 切り取り / 貼り付け
  - 複製
  - 元に戻す / やり直し

- **グリッド・スナップ**
  - メートル法ベースのグリッド
  - グリッドへのスナップ
  - オブジェクトへのスナップ
  - スマートガイド

- **縮尺・キャリブレーション**
  - 1:50〜1:300などの図面縮尺
  - 2点指定による縮尺補正
  - mm / cm / m に対応

- **レイヤー**
  - 表示 / 非表示
  - ロック
  - 並び順の変更
  - 壁、家具、寸法、注釈などをレイヤーごとに管理

- **背景画像**
  - 画像を背景として読み込み
  - 元の図面やスケッチを下敷きにしてトレース

- **インポート**
  - 別のFloorCanvasプロジェクトからオブジェクトや設定を取り込み

- **エクスポート**
  - PNG
  - SVG
  - PDF

- **タッチ操作**
  - 小さな画面やタッチ操作にも対応

## ブラウザ版

ブラウザ版ではElectronを必要としません。

プロジェクトは `.floormap.json` ファイルとして保存・読み込みできます。

対応ブラウザでは File System Access API を利用し、一般的なデスクトップアプリに近い感覚でファイルを開いたり、同じファイルに上書き保存したりできます。

File System Access API に対応していないブラウザでは、ファイル選択とダウンロード方式に自動的に切り替わります。

### ブラウザでの保存

基本的な流れは次のとおりです。

```text
プロジェクトを編集
↓
保存
↓
.floormap.json ファイルとして保存
↓
後から同じファイルを開いて編集を再開
```

ブラウザ版で読み込んだ背景画像は、必要に応じてプロジェクトファイル内に埋め込まれます。

## Windowsデスクトップ版

Windows版では、ユーザーが指定した **ワークスペースフォルダ** の中にプロジェクトを保存します。

例：

```text
D:\FloorCanvas Projects\
├── My Office\
│   ├── project.floormap.json
│   └── assets\
│
└── Apartment\
    ├── project.floormap.json
    └── assets\
```

各プロジェクトは、それぞれ独立したフォルダとして保存されます。

背景画像などのファイルは、そのプロジェクト内の `assets` フォルダに保存されます。

## 初回起動

Windowsデスクトップ版を初めて起動すると、プロジェクトの保存先となるワークスペースフォルダを選択します。

選択したワークスペースは次回以降も記憶されます。

設定済みのフォルダが削除されていたり、外付けドライブが接続されていなかったりする場合は、エラーで終了するのではなく、再試行または別のワークスペースを選択できます。

## 最後に開いたプロジェクト

Windows版では、最後に使用したプロジェクトを記憶します。

次回起動時、そのプロジェクトが存在し正常に読み込める場合は、自動的に前回の作業を再開します。

プロジェクトが移動・削除されていたり、ファイルが破損していたりする場合は、自動読み込みを中止し、通常の開始画面を表示します。

## 保存と「名前を付けて保存」

### 保存

すでにワークスペース内に保存されているプロジェクトでは、**保存** を選ぶと現在の `project.floormap.json` が更新されます。

毎回、上書き確認を行う必要はありません。

### 新規プロジェクト・サンプルを初めて保存する場合

まだ保存先のない新規プロジェクトや組み込みサンプルで **保存** を選ぶと、ワークスペース内に通常のFloorCanvasプロジェクトとして保存されます。

一度保存した後は、以降の **保存** で同じプロジェクトが更新されます。

### 名前を付けて保存

**名前を付けて保存** を選ぶと、ワークスペース内に新しいプロジェクトフォルダが作成されます。

必要な `assets` ファイルも引き継がれ、以降は新しく作成したプロジェクトが編集対象になります。

## 未保存の変更について

未保存の変更がある状態で、

- 新しいプロジェクトを作成する
- 別のプロジェクトを開く
- ワークスペースを変更する
- FloorCanvasを終了する

といった操作を行う場合は、変更内容を失わないよう確認が表示されます。

デスクトップ版を終了する際は、

- 保存
- 保存しない
- キャンセル

から選択できます。

## 組み込みサンプル

FloorCanvasには、主な機能を試せる3種類のサンプルが用意されています。

### Small Office

小規模オフィスを想定したサンプルです。

受付、オープンオフィス、会議室、個室、簡易キッチン、収納、トイレなどを配置しています。

### Apartment

マンション・アパートの住戸を想定したサンプルです。

玄関、リビング・ダイニング、キッチン、寝室、書斎・ゲストルーム、浴室、トイレ、収納、バルコニーなどを配置しています。

### Café / Small Retail

小規模なカフェ・店舗を想定したサンプルです。

客席、カウンター、キッチン・調理スペース、収納、スタッフスペース、トイレ、商品ディスプレイなどを配置しています。

これらのサンプルはすべて **FloorCanvas用に作成された架空のレイアウト** であり、実在する建物の図面を使用したものではありません。

## プロジェクトファイル

FloorCanvasのプロジェクトデータはJSON形式で保存されます。

```text
example.floormap.json
```

プロジェクトファイルには、主に以下の情報が含まれます。

- プロジェクト名
- 単位
- 縮尺
- 用紙設定
- グリッド設定
- レイヤー
- 部屋・壁・家具などのオブジェクト
- 背景画像に関する情報

`.floormap.json` ファイルは、ブラウザ版とデスクトップ版の両方で利用できます。

## プライバシー

FloorCanvasは、ローカルでの利用を基本としています。

プロジェクトの作成・編集・保存に、以下のサービスは必要ありません。

- ユーザーアカウント
- バックエンドサーバー
- クラウドストレージ
- クラウドデータベース
- テレメトリ

プロジェクトデータは、ユーザーが指定したローカルファイルまたはワークスペースに保存されます。

組み込みサンプルもすべて架空のデータです。

## 開発・ローカル実行

Node.js と npm が必要です。

依存パッケージをインストールします。

```bash
npm install
```

開発用Webサーバーを起動します。

```bash
npm run dev
```

本番用Webビルド：

```bash
npm run build
```

ビルド済みWeb版をローカルで確認：

```bash
npm run preview
```

## Electron / Windows版

開発モード：

```bash
npm run electron:dev
```

本番用WebビルドをElectronで起動：

```bash
npm run electron:preview
```

展開済みアプリを作成：

```bash
npm run electron:pack
```

Windows x64 ポータブル版を作成：

```bash
npm run electron:dist
```

## テスト

```bash
npm run lint
npm run build
npm run test:storage
npm run test:e2e
```

`test:storage` では、デスクトップ版のワークスペースやプロジェクト保存処理などをテストします。

`test:e2e` ではPlaywrightを使用し、ブラウザ版の編集、ファイル保存、組み込みサンプル、背景画像などの主要機能を確認します。
